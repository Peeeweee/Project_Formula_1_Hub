# Circuit venue photographs

The Learn F1 atlas now defaults to photographs of each named circuit or Grand Prix location. Track layouts remain available in a separate tab.

All 24 locations have manually selected Wikimedia Commons photographs stored in public/assets/venues. The manifest in src/data/venuePhotos.json records the original file, creator, description, date, source page and license. A public copy is available at assets/venues/ATTRIBUTION.json. Photos were reviewed as a contact sheet before integration. No keyword-based image search runs in the app.

These are reference venue images from different dates, not claims about the current layout or current race weekend. Las Vegas deliberately uses a 2013 Strip location photograph, labeled as predating the Grand Prix. If an image fails, the app explains that it is unavailable and offers retry or the separate layout view; it never substitutes a random photograph.
